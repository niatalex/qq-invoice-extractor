# QQ 邮箱本地发票提取工具

版本：**v1.0试用**　作者：**阿俊工作室**。试用仅为版本名称，没有期限或功能限制。

分享给好友：发送 `dist\发票提取工具_v1.0试用_阿俊工作室_Windows.zip`，好友解压后打开 `InvoiceExtractor` 文件夹，双击 `InvoiceExtractor.exe`。无需安装 Python 或 7-Zip；好友填写自己的邮箱和授权码。分发包不包含你的邮箱设置、授权码、发票或查询记录。适用于 Windows 10/11 64 位。

## 直接使用

双击 `dist\InvoiceExtractor\InvoiceExtractor.exe`。成品已包含 Python 和完整 7-Zip，运行无需安装它们。复制到其他电脑时请复制整个 `InvoiceExtractor` 文件夹，不能只复制 EXE。

1. 在 QQ 邮箱网页设置中开启 IMAP 服务并生成邮箱授权码。
2. 填写完整 QQ 邮箱地址和授权码（不是 QQ 密码），点击“测试连接”。授权码只需在本地填写，不要发给其他人。
3. 输入起止日期（YYYY-MM-DD，按北京时间收信日期，包含两端全天），选择保存目录。
4. 填写发件人或标题关键字，点击“开始提取”。默认标题为“发票”，发件人可以留空。
5. 双击结果预览 PDF，或打开保存文件夹。移除选中 PDF 会先要求确认。

## 筛选规则

- 发件人和标题关键字均可留空，每行一个条件，也支持分号分隔。
- 发件人邮箱精确匹配，显示名称包含匹配。标题解码后不区分大小写地包含匹配。
- 每组内部满足任意条件即可，两组同时填写时必须同时满足。
- 仅标题填“发票”：查询该时间段所有标题包含“发票”的邮件。
- 仅发件人填写：查询该发件人的邮件，不限制标题。
- 两组都留空：提示后查询时间段内全部邮件附件。
- 只读查询收件箱，不修改邮件或已读状态，不访问正文下载链接。

## 保存与去重

PDF 保存到所选目录的“发票”子目录。SQLite 数据库和每次查询 CSV 保存到“.invoice-extractor”子目录。CSV 包含筛选条件、邮件标题、来源、保存位置、重复及失败项。保持同一保存目录并保留数据库，可跨查询去重。

相同字节按 SHA-256 去重；不同字节仅在可靠识别出的完整发票号码、销售方税号、价税合计金额三者一致时合并，任何不确定情况保留。扫描件不做 OCR，仅按哈希去重。被移动、删除或更改的历史文件不会阻止重新提取。

提取全部 PDF，可能包含非发票文件。移除功能仅删除数据库登记、仍在输出目录且内容未变的文件；不删除邮箱附件或用户其他文件。不要同时用多个程序实例写入同一输出目录。

## 压缩包与异常

支持 ZIP、RAR、7Z 以及嵌套包；密码包临时询问密码，可跳过，不保存密码。最大嵌套 4 层、单文件 100 MB、单邮件 150 MB、每任务累计解压 500 MB、每包 1000 项。拒绝越界路径和链接，不把压缩包内部路径直接写入磁盘。

失败邮件或附件记录到 CSV，其余继续处理。取消保留已经保存的文件及清单，当前网络操作最多约 30 秒。断网后可重新查询，已经保存的发票自动去重。

## 本地数据

邮件和 PDF 不上传第三方。勾选保存授权码时使用 Windows 凭据管理器，条目名为 `LocalInvoiceExtractor/邮箱地址`。取消勾选后执行测试或提取会删除该邮箱原先保存的授权码。配置位于 `%LOCALAPPDATA%\LocalInvoiceExtractor\settings.json`，只记录邮箱、保存目录和选项，不包含授权码。压缩密码会作为短时 7-Zip 子进程参数使用。

## 源码构建

使用 Python 3.11+；双击 `build.bat`，脚本在项目 `.venv` 中安装依赖，测试通过后用 PyInstaller 打包。仓库的 `vendor` 已有完整压缩组件；如果组件缺失，先安装官方完整 7-Zip，构建脚本会复制本机组件。仅有 7za 不支持 RAR。

源码运行：`pip install -r requirements.txt` 后执行 `python app.py`。测试：`python -m unittest discover -s tests -v`。成品启动检查：`InvoiceExtractor.exe --smoke-test`。

真实 QQ 邮箱尚需由使用者在本地填写授权码验收；程序测试使用模拟邮件，不访问真实邮箱。

第三方组件：7-Zip 来自 https://www.7-zip.org/download.html，许可随成品保留；RAR 测试样本来自 https://github.com/markokr/rarfile/tree/master/test/files 。Python 依赖许可参见各包分发信息。
